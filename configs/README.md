# Configurations

Example model and experiment configurations are stored here. Configurations use
relative or user-provided paths and do not refer to governed datasets, private
checkpoints or a particular workstation.

The ITV examples cover Llama 3.1, Llama 3.2, Mistral, Gemma 2 and Phi-4 with their
model-specific Unsloth chat-template names. Replace both placeholder adapter paths
before running them. `llama31_beam_huggingface.json` demonstrates generator-only
beam decoding through Transformers.
